## ✨ Descripción

**Go Trip** es una plataforma para planificar viajes que permite descubrir destinos, guardar favoritos, gestionar reservas y más. Esta aplicación ofrece una interfaz moderna y compatibilidad móvil, ideal para viajeros que quieren una experiencia rápida y funcional.

Este repositorio contiene el **frontend**, desarrollado con React, JavaScript, Tailwind CSS y Material Tailwind.

---

## 🚀 Funcionalidades

- ✈️ Explora destinos populares y actividades.
- ❤️ Guarda lugares y actividades en favoritos.
- 📲 Diseño responsive para móvil y escritorio.
- 🔐 Integración con backend para usuarios, reservas y autenticación.
- 📷 Subida y almacenamiento de imágenes con Cloudinary
- 🟢 Soporte al usuario a través de **WhatsApp**.

## 🛠️ Instalación local

1. **Clona el repositorio:**

```bash
git clone https://github.com/EstefaniaDelgado/Booking-GoTrip.git
cd go-trip-frontend
npm install
```
2. Configura las variables de entorno:

Crea un archivo .env en la raíz del proyecto y agrega tus claves:

```bash
VITE_APP_API_URL=URL_LOCALHOST
VITE_APP_URL_DEPLOYMENT=URL_DEL_DEPLOY
VITE_UPLOAD_PRESENT=UPLOAD_PRESENT
VITE_CLOUD_NAME=CLOUD_NAME
```

3. Inicia el servidor de desarrollo:
   
 ```bash
npm run dev
```

4. Abre tu navegador en http://localhost:5173
